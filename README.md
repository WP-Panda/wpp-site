# Wp Panda — сайт-маркетплейс тем и плагинов WordPress

Репозиторий содержит **статическую вёрстку** сайта-витрины «Wp Panda» и **готовую тему WordPress**, которая воспроизводит эту вёрстку и весь её функционал **1 в 1**. Магазин работает на плагине **WooCommerce** — тема не подменяет логику магазина, а только переопределяет вывод (шаблоны) и добавляет удобные сущности поверх: лицензионные ключи, тикеты поддержки, избранное.

```
├── html-layout/   — исходная статическая вёрстка (источник правды, не изменяется)
├── wp-panda/      — тема WordPress (ставится в wp-content/themes/)
└── README.md
```

---

## 1. Что это за проект

«Wp Panda» — витрина цифровых продуктов: **тем для WordPress** (лицензия «1 сайт» или «5 сайтов») и **плагинов** (лицензия «навсегда»). Сайт включает:

- главную страницу-лендинг с подборкой товаров;
- каталог с фильтрами/сортировкой и карточками товаров;
- детальную страницу товара с галереей, выбором лицензии, табами (описание, отзывы, комментарии, история версий);
- корзину, оформление заказа со степпером из 4 шагов и страницу «Спасибо за покупку» с выдачей лицензионных ключей;
- личный кабинет покупателя (заказы, загрузки, лицензии и ключи, тикеты поддержки, избранное, адрес, данные аккаунта);
- блог, базу знаний, FAQ, страницу UI-кита, поиск, страницу 404.

Старая тема `wp-panda` была **удалена и создана заново** поверх той же вёрстки: разметка, классы, тексты и поведение интерактивных элементов повторяют статические страницы из `html-layout/` (включая оверлеи — корзину-дровер, поиск, уведомления, мобильное меню — которые были извлечены запуском исходного SPA-бандла).

## 3. Быстрый старт

1. **Требования:** WordPress 6.2+, PHP 7.4+, WooCommerce 8.x+, доступ в интернет у самого сайта (для скачивания картинок демо не нужен — они лежат в теме).
2. Положите папку `wp-panda/` в `wp-content/themes/` и активируйте тему.
3. Убедитесь, что плагин **WooCommerce** установлен и активирован (магазин целиком на нём).
4. При активации темы на пустом магазине демо-контент импортируется автоматически. Вручную: **Консоль → Инструменты → Демо Wp Panda → «Импортировать демо-контент»**.
5. Импорт создаёт: 17 продуктов (8 тем с вариациями «1 сайт/5 сайтов», 8 плагинов, бандл All Access), 12 статей блога с обложками, 21 статью базы знаний, страницы «База знаний», «Частые вопросы», «UI-кит», статическую главную, главное меню, настройки магазина (валюта ₽, формат цен) и постоянные ссылки `/%postname%/`.

После импорта:

- `/` — главная; каталог — страница магазина WooCommerce;
- страница товара — с выбором лицензии и табами;
- `/корзина` (страница «Корзина» из чекаута), оформление заказа со степпером, страница «Спасибо»;
- `/личный-кабинет/` — кабинет покупателя (включая эндпоинты `…/лицензии`, `…/поддержка`, `…/избранное`);
- `/блог/`, `/база-знаний/`, `/фақ/` (страница «Частые вопросы»), страница «UI-кит».

> Точные адреса зависят от слагов, созданных WooCommerce и импортером; при необходимости переименуйте страницы в консоли.

## 4. Как устроен магазин

- **Товары.** Темы — продукты типа *variable* с атрибутом «Количество сайтов» (вариации «1 сайт» и «5 сайтов», у каждой своя цена). Плагины — простые продукты с лицензией «навсегда». У каждого товара хранятся: арт карточки (точь-в-точь из вёрстки), мини-арт, версия, требования, совместимость, история версий, счётчики продаж.
- **Корзина.** Нативная корзина WooCommerce со своим шаблоном: строки с артом товара, переключение варианта лицензии прямо в строке (без перезагрузки), промокоды, итоговая панель «Ваш заказ», мобильная нижняя панель.
- **Оформление.** Три карточки полей: «Контактные данные» (имя, фамилия, email, телефон), «Платёжные данные» (страна, город, компания, ИНН), «Дополнительно» (домен для активации, источник, комментарий). Поля — стандартные поля WC (со всеми проверками), лишние адресные поля скрыты. Способ оплаты и кнопка «Перейти к оплате» — штатный блок WC, оформленный под макет.
- **Оплата.** Любая платёжная система, доступная в WooCommerce (по умолчанию — «Оплата наличными» для теста). После успешной оплаты страница «Спасибо» показывает купленные продукты, **лицензионные ключи** и ссылки на скачивание.
- **Лицензионные ключи.** Генерируются автоматически при переходе заказа в статус «Выполнен» или «В обработке»: по одному ключу формата `WPP-XXXX-XXXX-XXXX` на каждую позицию (для вариаций — с учётом тарифа). Ключи видны на странице «Спасибо», в разделе «Лицензии и ключи» кабинета и в панели управления.
- **Избранное.** Кнопка-сердце на карточках; для авторизованных хранится в метаданных пользователя, для гостей — в сессии, при входе объединяется. Раздел «Избранное» в кабинете показывает живые карточки каталога.
- **Поддержка.** Раздел «Поддержка» в кабинете: список тикетов, переписка, форма «Новое обращение» (продукт, тема обращения, заголовок, сообщение). Тикеты — приватные записи служебного типа `wpp_support_ticket`, видимые только автору и администратору.

## 6. Разработка и проверка

- Вёрстка в `html-layout/` **не меняется** — это источник правды. Любое изменение темы сверяется с ней.
- Все PHP-файлы темы проходят `php -l` без ошибок.
- Стили: `assets/css/layout.css` = полная копия собранного `html-layout/styles.css` + дописанный в конце раздел адаптации под «живой» вывод WordPress и WooCommerce (формы, уведомления, блок оплаты, таблицы заказов, форма отзывов, пагинация).
- Скрипты: `assets/js/theme.js` — единый файл без сборщиков; контракт с сервером описан в `wp-panda/README.md`.
- Локальный прогон: `wp-now start` в папке темы (или любая среда с установленным WooCommerce), затем импорт демо.

## 7. Лицензия и авторство

Вёрстка и контент принадлежат проекту «Wp Panda». Тема собрана по этой вёрстке; код темы распространяется вместе с проектом.
