Премиальная тема магазина тем и плагинов для WordPress и WooCommerce в фирменном стиле Wp Panda.

== Description ==

Тема повторяет дизайн магазина Wp Panda: главная с витриной продуктов, каталог,
карточка товара с CSS-макетами демо-сайтов, корзина-шторка, блог, база знаний,
FAQ с аккордеонами, форма поддержки и личный кабинет WooCommerce.

= Возможности =

* Главная страница: hero, преимущества, витрина с фильтром «Темы/Плагины»,
  решения, FAQ, последние статьи, отзывы, CTA.
* Интеграция WooCommerce целиком через хуки и фильтры: тема не переопределяет
  шаблоны WooCommerce — используется только универсальный woocommerce.php
  (шапка/подвал темы + woocommerce_content()). Каталог, карточка товара,
  корзина, чекаут и кабинет настраиваются в inc/woo.php
  (30+ action/filter: карточки цикла, шапка витрины, хлебные крошки, порядок
  блоков карточки, похожие товары, AJAX-фрагменты корзины-шторки, формат цены,
  пагинация и бейджи распродажи). Без WooCommerce тема работает в демо-режиме
  с каталогом из inc/demo.php.
* Корзина-шторка на AJAX-фрагментах WooCommerce.
* База знаний — тип записи kb_article с разделами (kb_cat), индексом и
  сайдбаром-аккордеоном на страницах статей.
* FAQ — тип записи faq_item с категориями; страница-шаблон «FAQ» и блок на главной.
* Поддержка — страница-шаблон с формой (admin-post + wp_mail, nonce, анти-спам).
* Меню: шапка + три колонки футера. Логотип: кастомный или panda.svg из темы.
* Всё на ванильном JS (~9 КБ) без jQuery-зависимостей темы.

= Быстрый старт =

1. Активируйте тему.
2. Создайте страницы: «Главная» (шаблон по умолчанию), «Блог», «FAQ»
   (шаблон «FAQ»), «Поддержка» (шаблон «Поддержка»). При активном WooCommerce
   страницу каталога создаёт сам WooCommerce (WooCommerce → Настройки).
3. В Настройки → Чтение выберите: главная — статическая страница «Главная»,
   страница записей — «Блог».
4. В Настройки → Постоянные ссылки выберите «Название записи».
5. Заполните меню: Внешний вид → Меню (область «Меню в шапке»).
6. С контентом: Записи, База знаний → Добавить статью, FAQ → Добавить вопрос.

= WooCommerce =

Активируйте WooCommerce и создайте товары. Для карточек в стиле Wp Panda
добавьте товарам произвольные поля (или используйте ACF):

* `_wpp_type`       — theme | plugin
* `_wpp_badge`      — бейдж на карточке (например, «Хит продаж»)
* `_wpp_version`    — версия продукта
* `_wpp_image`      — URL фото для макета демо-сайта темы
* `_wpp_image2`     — второй URL (внутренняя страница)
* `_wpp_color` / `_wpp_color2` / `_wpp_bg` — цвета превью
* `_wpp_icon`       — иконка плагина: rocket, shield, zap, form, cart-w, languages, calendar, mail
* `_wpp_hero_title` / `_wpp_eyebrow` / `_wpp_inner_title` — тексты в макете
* `_wpp_chips`      — плашки на баннере плагина через «|»

Категории товаров «Темы» и «Плагины» используются фильтром витрины.
