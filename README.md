# Wp Panda WordPress theme

The installable WordPress + WooCommerce theme is in [`wp-panda/`](wp-panda/). Install that folder as a theme; the original static layout remains preserved in [`html-layout/`](html-layout/).

See [`wp-panda/README.md`](wp-panda/README.md) for setup steps, classic WooCommerce template overrides, retained hooks, and the distinction between WooCommerce PHP templates and Cart/Checkout Blocks.
